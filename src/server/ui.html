🤖 Autopilot (full automation loop)

Worker har ~30s mein: sources poll → analyze → clips → edit → QC → title/thumbnail → (review) → upload-unlisted → verify → schedule → publish → analytics → comments. Default sab OFF.

Publish/public gates aur auto-approve safety ke liye sirf server par badalte hain (yahan se nahi). Server shell/Termux mein: npm run cli -- autopilot on --publish --yes (private/unlisted tak) · ... --approve --public --yes (auto public) · npm run cli -- autopilot off.

🔑 AI keys — sirf key daalo, Save dabao

Model ke naam pehle se set hain. Kisi bhi provider ki key paste karo → Save → turant "Connected" ya error dikhega. Ek se zyada save karoge to baaki fallback ban jate hain. Key nahi hai to bhi app chalta hai (local engine).

Ya project folder ki .env file mein likho: GROQ_API_KEY=gsk_... · GEMINI_API_KEY=AIza... · OPENROUTER_API_KEY=sk-or-... · XAI_API_KEY=xai-... (Ollama: OLLAMA=1). Server restart par ya is button se apne aap detect + test + save.

🎙️ Local speech-to-text (bina API, captions ke liye)
