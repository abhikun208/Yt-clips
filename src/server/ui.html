🔑 AI keys — sirf key daalo, Save dabao
Model ke naam pehle se set hain. Kisi bhi provider ki key paste karo → Save → turant "Connected" ya error dikhega. Ek se zyada save karoge to baaki fallback ban jate hain. Key nahi hai to bhi app chalta hai (local engine).
Ya project folder ki .env file mein likho: GROQ_API_KEY=gsk_... · GEMINI_API_KEY=AIza... · OPENROUTER_API_KEY=sk-or-... · XAI_API_KEY=xai-... (Ollama: OLLAMA=1). Server restart par ya is button se apne aap detect + test + save.

  
☁️ Cloud storage (rclone) — bada source cloud mein, phone khali
Apna cloud (Google Drive / OneDrive / Backblaze / MEGA / 1 TB wala plan) rclone se jodo: login browser mein rclone khud karta hai, is project ko password nahi milta. Jab ek video ke saare clips Published ho jate hain, original cloud mein copy (size verify) hota hai, phir local se delete (agar chaho). Dobara edit chahiye to wapas apne aap aa jata hai. Dhyan: editing ke dauran original local disk par hona zaroori hai, isliye "ek baar mein video" 1 rakho.

  

  

 
🎙️ Local speech-to-text (bina API, captions ke liye)
Audio device/server par hi text banta hai (Whisper engines). API key tabhi lagti hai jab aap "API" chuno. VoiceStudio ka code copy nahi kiya (AGPL desktop app); uska local server chal raha ho to use bhi backend ban sakta hai.
